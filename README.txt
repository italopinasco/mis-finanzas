MIS FINANZAS - PWA

App móvil para PEN/USD, saldo acumulado, ahorro, recurrentes, tipo de cambio y sueldo con impuesto configurable del 8%.

Los datos se guardan localmente en el dispositivo. Para instalarla como app en Android/iPhone hay que publicarla en HTTPS (por ejemplo GitHub Pages, Netlify o un hosting) y luego elegir Instalar/Añadir a pantalla de inicio.
